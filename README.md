# Hack & Juice write-ups

Write-ups of the OWASP Juice Shop challenges we solved during Hack & Juice, a cybersecurity hackathon at Epitech (December 2025). Juice Shop is a web shop that is vulnerable on purpose, made to practice web attacks.

Written by Simon Slack and [Jules Fischer](https://github.com/Jules-Epitech).

## What's in a write-up

One file per challenge, named `Category-Difficulty-Name.md`:

- Methodology: what we tried, step by step, with screenshots in `assets/`
- Vulnerability: type, affected component, severity
- Risks
- Actions: how to fix it

Tools: Burp Suite, browser devtools.
