# 🧃 Hack & Juice — Cybersecurity CTF Challenges

**3rd place France 🇫🇷 — Hackathon Hack & Juice by Epitech**

## 🎯 What is this?

Hack & Juice is an Epitech cybersecurity project based on 
OWASP Juice Shop — a deliberately vulnerable web application 
designed to train developers and security engineers on 
real-world attack techniques.

This repo documents all the challenges solved during the 
Hack & Juice hackathon, where our team ranked **3rd in France**.

## 🔓 Vulnerabilities covered (OWASP Top 10)

- **Injection** — SQL Injection, NoSQL Injection, Login bypass
- **Broken Authentication** — Password reset attacks, 
  credential exploits
- **Broken Access Control** — CSRF, product tampering, 
  Easter eggs
- **Sensitive Data Exposure** — Log access, developer backups
- **Cryptographic Issues** — Nested Easter eggs, forged coupons
- **Improper Input Validation** — Null byte injection, 
  payback exploits
- **Broken Anti-Automation** — CAPTCHA bypass, multiple likes

## 📁 Structure

Each file = one challenge solved, with:
- Context and objective
- Step-by-step exploitation methodology
- Tools used
- Key learnings

## 🛠️ Tools used

- Burp Suite
- Browser DevTools
- SQL/NoSQL injection techniques
- JWT analysis
